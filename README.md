# harbour-cph

===================

#Sailfish Captive Portals Helper

A simple app to view CPH web interface through a silica webviewer.

##Good things:

 1.   Avoid using android app.
 2.   Don't need to occupy the browser for this
 3.   No bar in the bottom

##Bad things:
 1.   No notifications
 2.   Not sure about battery consumption vs android app
